# PageIntro

## Purpose
Standardized intro section for public pages with title and description.

## Props
- eyebrow?: string
- title: string
- description: string

## Usage
```tsx
<PageIntro
  eyebrow="Vini Painting"
  title="Services"
  description="Professional painting services in Orlando"
/>
```

## Tests
- Validates heading, description and optional eyebrow rendering.
